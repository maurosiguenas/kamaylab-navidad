# KamayLab · Colección Navidad 2026

Página de la colección navideña de KamayLab. Cada producto se pide por WhatsApp.

- Para cambiar precios, productos o el número de WhatsApp: edita el bloque `EDITA AQUÍ` dentro de `public/index.html`.
- La página está en `public/index.html` y las fotos en `public/img/`.
- Se publica en Cloudflare Workers (static assets) con `wrangler.jsonc`.
